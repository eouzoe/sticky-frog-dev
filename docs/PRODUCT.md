# 產品方向與路線（2026-10-30）

這份是避免遺忘用的紀錄：定位、做決定的原則、第一版範圍、以及明確「不在第一版」但之後要做的東西。
技術問題清單在 REVIEW-2026-10-30.md。

## 定位

- CrazyGames 上的小遊戲，現階段是**驗證市場**：有數據證明會受歡迎之後，才考慮獨占、重構玩法與畫風、換平台、加大投入。
- 核心資產只有一個：**一直盪的手感、一局接一局、沒事就想玩一下**。
- 美術往小遊戲方向走：乾淨、清楚、不卡。不追精緻，不佔效能，但也不是粗製濫造。
- 之後靠短影音（AI 批量剪輯精華片段、同模板換配樂換素材大量投放）引流回來。

## 做決定時用的原則

1. **盪的過程中永遠不能卡一下。** 熱迴圈零配置、遊玩中不寫 DOM、音效不能一幀建幾十個節點、SDK 不能擋主執行緒。一次 100 ms 的停頓就毀掉那一盪。
2. **流程不打斷。** 落地那一下的停頓是唯一的節拍。關與關之間沒有按鈕、沒有廣告、沒有選單。
3. **預算給玩法層。** 鉤子、荷葉、危險物、角色、舌頭、回饋優先；背景只負責襯托，而且不動用資源。
4. **每個改動都要便宜。** 模組小、邊界清楚、模擬與計分有測試鎖住行為，改完自己能驗證，不用等人試玩才知道壞了。
5. **一切可量。** 漏斗事件是功能的一部分，不是事後加的。
6. **一切可重播。** 一局＝種子＋輸入序列。這是回放、導出、批量剪輯的共同地基。

## 第一版：遊戲本體

目標：一個使用者試玩後覺得「完全可行」的版本。本地完成、jj 原子提交排好；**在使用者說可以之前不推送、不開 PR**。

- 低階手機 60 fps 不卡頓：三層視差背景、平塗水面與漸層天空、開機拆成核心與延後模組、永不等 SDK、零配置熱迴圈、音效預先算成緩衝。
- 止血：存檔合併（版本號、時間戳、逐欄合併）、無盡模式結算、語言選擇存檔、WebGL context lost、世界圖集洩漏。
- 流程：關卡結束沒有任何按鈕；顯示星星與金幣後無條件進下一關；顯示要短而刻意，分「豪爽」與「可惜再來」兩套節拍，時間固定；主線與無盡統一成一個流。
- 金幣：遊戲中有難度地取得；當下噴出、短暫懸空、飛到左上角計數器，數字在到達那一刻才跳。減少獲取量讓它珍貴。
- 回放地基：錄製格式進存檔、可決定性重播、遊戲內能看回放。導出不在第一版。
- 主題地基：主題定義成資料包（角色零件圖集、舌頭、拖尾、旋轉與落地動畫、音效組、可選地圖層）；旋轉貓做成第一個完整主題。
- 量測：局長、每局關數、重試率、無盡距離分布、流失點、「想買但不夠」的瞬間。
- 專案整潔：過期測試與 devenv 設定清掉、文件更新。

### 第一版就要留好的接口（之後補會很貴）

- 錄製：種子＋輸入序列進存檔格式；輸入要帶物理步編號，不帶牆鐘時間。
- 渲染：能用固定時步、在離屏畫布、以任意解析度重畫；鏡頭能被腳本控制。
- 主題：資料包的載入路徑（圖集＋設定＋音效組），引擎不認識任何特定主題。
- 遙測：事件格式固定，精彩局（種子＋輸入，幾百位元組）能上傳。

### 待使用者確認的預設

- 六個世界共用背景結構，只換色和一兩層特色元素，危險物照舊。這是最便宜的做法，差異會比現在小一點。
- 導出影片放第二階段。

## 第二階段之後（記下來，不在第一版）

### 回放與導出

- 導出格式：瀏覽器內用 WebCodecs 編 H.264，加一個約 20 KB 的 MP4 封裝器，直接產出標準 MP4，不需轉換，各平台直接吃。「支援所有主流格式」實務上就是 MP4。
- 預設組：TikTok／Shorts 9:16（1080×1920，長度上限）、YouTube 16:9、方形；各自的安全邊距。畫質分級（解析度、位元率）。
- 長度：片段＝回放裡的一段時間範圍，不是整局。
- 手機上用系統分享把檔案丟進 TikTok 等 App；直接 API 上傳要申請開發者帳號，再說。
- 聲音：音效是程序合成，導出時用離線音訊環境跟著重播算，逐幀對齊。配樂在批量工具那邊加。

### 內建剪輯

可行，而且便宜，因為「片段」不是影片檔，是「回放加參數」，剪輯等於改參數再渲染一次。能做的：

- 選時間範圍、標慢動作點、換主題、換比例裁切、換鏡頭距離。
- 不做的：多軌時間軸、轉場、字幕特效。那是剪輯軟體的事，交給批量工具。

### 批量剪輯工具（自己做，離線）

- 無頭瀏覽器跑同一個重播引擎逐幀輸出，ffmpeg 合成。基礎設施跟烘焙工具是同一套。
- 模板：開場、慢動作點、結尾導流畫面；配樂庫輪換；主題輪換；比例輪換。同一局換十套主題和十首配樂就是一百支影片。
- 來源：遙測上傳的真實高分局，或自動玩家跑出來的局。
- 輸出：批量 MP4 加中繼資料（哪一局、哪個主題、哪首配樂），投放後對照反應。

### 主題與地圖

- 主題用形象不用名字（蛛絲緊身衣、人猿），不處理版權問題。
- 地圖包（高樓大廈、叢林）跟主題一起打包賣。
- 看廣告免費體驗一次、金幣解鎖；活動關卡要金幣或廣告，主線免費。
- 官方 TikTok 贈送主題和金幣（兌換碼）。
- 第一版只做貓一個完整主題走通整條路，驗證的是機制不是目錄。

### 經濟

- 金幣獲取量低、入帳要有感；每一次「想買但不夠」都記錄，作為定價依據。

### 社交（可能不需要）

- 用戶主頁、好友、排行。CrazyGames 有平台排行可以先用，自己做的放最後。

### 短影音營銷

- 官方帳號、批量投放、模板不斷切換配樂與素材，看反應，引流回 CrazyGames。
